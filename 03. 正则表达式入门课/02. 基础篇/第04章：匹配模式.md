# 不区分大小写模式（Case-Insenstive）

首先，我们来看一下不区分大小写模式。它有什么用呢？学一个知识的时候，我一般喜欢先从它的应用出发，这样有时候更能激发我学习的乐趣，也更容易看到学习成果。
下面我来举个例子说明一下。在进行文本匹配时，我们要关心单词本身的意义。比如要查找单词 cat，我们并不需要关心单词是 CAT、Cat，还是 cat。根据之前我们学到的知识，你可能会把正则写成这样：`[Cc][Aa][Tt]`，这样写虽然可达到目的，但不够直观，如果单词比较长，写起来容易出错，阅读起来也比较困难。
![匹配模式（一）](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/%E6%9E%81%E5%AE%A2%E6%97%B6%E9%97%B4/%E7%AC%AC03%E7%AB%A0%EF%BC%9A%E6%AD%A3%E5%88%99%E8%A1%A8%E8%BE%BE%E5%BC%8F%E5%85%A5%E9%97%A8%E8%AF%BE/%E7%AC%AC%E5%85%AD%E7%AB%A0%EF%BC%9A%E5%8C%B9%E9%85%8D%E6%A8%A1%E5%BC%8F%EF%BC%9A%E4%B8%80%E6%AC%A1%E6%80%A7%E6%8E%8C%E6%8F%A1%E6%AD%A3%E5%88%99%E4%B8%AD%E5%B8%B8%E8%A7%81%E7%9A%84%204%20%E7%A7%8D%E5%8C%B9%E9%85%8D%E6%A8%A1%E5%BC%8F/%E5%8C%B9%E9%85%8D%E6%A8%A1%E5%BC%8F%EF%BC%88%E4%B8%80%EF%BC%89.png)
那么有没有更好的办法来实现这个需求呢？这时候不区分大小写模式就派上用场了。
我么前面说了，不区分大小写是匹配模式的一种。当我们把模式修饰符放在整个正则前面时，就表示整个正则表达式都是不区分大小写的，模式修饰符是通过（? 模式标识）的方式来表示的。我们只需要把模式修饰符放在对应的正则前，就可以使用指定的模式了。在不区分大小写模式中，由于不区分大小写的英文是 Case-Insenstive，那么对应的模式标识就是 l 的小写字母 i，所以不区分大小写的 cat 就可以写成（?!）cat。
![不区分大小写（二）](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/%E6%9E%81%E5%AE%A2%E6%97%B6%E9%97%B4/%E7%AC%AC03%E7%AB%A0%EF%BC%9A%E6%AD%A3%E5%88%99%E8%A1%A8%E8%BE%BE%E5%BC%8F%E5%85%A5%E9%97%A8%E8%AF%BE/%E7%AC%AC%E5%85%AD%E7%AB%A0%EF%BC%9A%E5%8C%B9%E9%85%8D%E6%A8%A1%E5%BC%8F%EF%BC%9A%E4%B8%80%E6%AC%A1%E6%80%A7%E6%8E%8C%E6%8F%A1%E6%AD%A3%E5%88%99%E4%B8%AD%E5%B8%B8%E8%A7%81%E7%9A%84%204%20%E7%A7%8D%E5%8C%B9%E9%85%8D%E6%A8%A1%E5%BC%8F/%E4%B8%8D%E5%8C%BA%E5%88%86%E5%A4%A7%E5%B0%8F%E5%86%99%EF%BC%88%E4%BA%8C%EF%BC%89.png)
你看，和 `[Cc][Aa][Tt]` 相比，这样是不是清晰简洁了很多呢？
我们也可以它来尝试匹配两个连续出现的 cat，如下图所示，你会发现，即便是第一个 cat 和第二个 cat 大小写不一致，也可以匹配上。
